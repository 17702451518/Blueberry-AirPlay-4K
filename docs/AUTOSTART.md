# 开机启动说明

## 默认行为

蓝莓 AirPlay 4K 默认不登记开机启动。打开控制台、切换画质模式或手动开始投屏，都不会创建开机启动项。

## 可选后台启动

只有用户主动勾选“开机启动后台投屏核心”并在二次确认中选择“是”，程序才会登记当前 Windows 用户的：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\BlueberryAirPlay4K
```

该项直接启动 `uxplay-windows.exe`，不会打开中文控制台。Windows 的 `Run` 键会在用户每次登录时运行登记的命令。

## 关闭与迁移

v3.1.1 的“关闭本程序所有目录的开机启动”按钮删除的只有 `BlueberryAirPlay4K` 这一项：

- 不删除整个 `Run` 键；
- 不修改其他软件的启动项；
- 不停止当前投屏；
- 不修改分辨率、帧率、编码器或渲染配置；
- 即使程序目录已经移动或删除，也能移除旧路径登记。

界面按登记项是否存在显示状态，而不是只检查它是否指向当前目录，因此搬动程序后不会再误报“未登记”。Windows 任务管理器仍可独立禁用已登记的启动项。
