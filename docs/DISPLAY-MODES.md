# 显示方式与窗口状态

显示方式只决定接收到的画面如何显示，不改变手机编码码率、发送分辨率或帧率。切换后无需重新连接。

| 显示方式 | 普通窗口 | 最大化：保留任务栏 | 全屏：隐藏任务栏 |
| --- | --- | --- | --- |
| 原始尺寸（100%） | 按接收画面的实际像素大小建立窗口，可超出屏幕 | 工作区内显示原始像素，超出部分可平移 | 覆盖显示器，仍按原始像素显示，可平移 |
| 等比窗口 | 调整大小时保持画面比例，不额外增加黑边 | 在工作区内建立尽可能大的等比窗口，宽或高达到边界 | 覆盖显示器并完整显示等比画面，比例不同时保留留白 |
| 适应窗口 | 窗口可自由调整，画面等比适应，允许黑边 | 填满工作区，画面完整显示 | 覆盖显示器，画面完整显示 |

“无黑边、完整画面、铺满不同宽高比的屏幕”不能同时满足。本项目不会为填满屏幕而拉伸图像，也不会悄悄裁掉源画面。等比窗口无额外黑边指普通窗口和保留任务栏最大化；全屏则使用整个显示器作为显示区域。

- 全屏由控制台的窗口状态选项切换，不注册 F11 快捷键。
- Esc：退出全屏或自定义最大化，返回普通窗口。
- 标题栏最大化：相当于保留任务栏最大化；等比模式使用自定义最大尺寸，而非系统强制铺满。
- 原始尺寸超出可见区域时，方向键平移；滚轮纵向平移，Shift + 滚轮横向平移。
- 隐藏画面窗口后，可选择任一窗口状态重新显示。停止接收器会结束投屏。

100% 指一个接收视频像素对应一个 Windows 物理屏幕像素，不受系统 125%/150% 界面缩放影响；不是“无损 AirPlay”。压缩损失、手机主动降分辨率及源视频自带黑边不能靠显示模式消除。

需要包含新接收核心的完整预览包；旧核心下控制台会禁用这些选项。任务栏全屏行为及多屏 DPI 仍需要实机验证。
