# 蓝莓 AirPlay 4K

把 iPhone/iPad 屏幕无线显示到 Windows 电脑上。

完整解压后双击根目录的 **蓝莓投屏.exe**。需要 .NET 8 Desktop Runtime x64。手机和电脑连接同一个局域网，在控制台点击“启动接收器”，再在手机控制中心的“屏幕镜像”中选择蓝莓投屏。

## 目录

- `蓝莓投屏.exe`：启动入口，不要单独移动。
- `app/`：中文操作界面。
- `runtime/`：投屏核心及运行依赖，不要删减或单独移动 DLL。
- `docs/`：完整说明、来源、更新记录和第三方许可证说明。
- `LICENSE`：控制台许可证；上游许可证另保留在 `runtime/LICENSE.rtf`。

当前是 v3.2.0-preview.6 显示控制预览版。新增原始尺寸（100%）、等比窗口、适应窗口；每种均支持保留任务栏最大化和隐藏任务栏全屏。点选显示方式或窗口状态即可切换，无需重新连接。Esc 返回普通窗口（已移除固定 F11 快捷键）。原始尺寸超出屏幕时用方向键或滚轮平移；Shift + 滚轮横向平移。详见 docs/DISPLAY-MODES.md。

停止按钮在接收器运行时显示红底白字，停止后显示浅红底深红文字。实验性 120 帧不保证实际达到；任务栏分组取决于 Windows 合并设置。详情见 docs/EXPERIMENTAL-120FPS.md。

本版重新构建了接收核心与相关依赖，不可只覆盖旧版控制台。已通过本机 D3D11 测试画面验证；iPhone/iPad 全链路、任务栏视觉行为、多屏 DPI 仍需实机测试。100% 是接收像素映射，不是无损编码。

接收器运行状态仅表示后台进程是否运行，不表示手机连接状态。本版修正了进程运行时始终显示“正在等待连接”的不准确提示，并调整了实验性模式的界面说明。

新版调整了目录，不代表已经减少解码依赖。默认仍为 4K60；原有用户配置不会因解压而改变。升级前备份原目录，退出旧接收器，再启动新版。需要关闭旧开机启动登记时，在控制台启动设置中点击关闭按钮。
