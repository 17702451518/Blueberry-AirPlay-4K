# 投屏名称

从 v3.2.0-preview.9 起，手机「屏幕镜像」列表中的默认接收端名称为 **电脑名称-投屏模式**。例如，同一网络内的 `DESKTOP-ABC-4K60` 与 `LAPTOP-XYZ-4K60` 对应两台电脑；低延迟模式显示为 `DESKTOP-ABC-4K60-低延迟`。

默认名称在运行时读取当前 Windows 电脑名称，发布包不会预先写入维护者的电脑名称。若两台电脑的 Windows 名称相同，请分别自定义名称，或在 Windows 中修改其中一台电脑的设备名称。

## 自定义与恢复默认

在控制台「投屏名称」中输入名称，如「客厅电脑」或 `Meeting Room 2`，下方会实时预览手机将看到的完整名称。模式后缀由程序自动附加，切换画质后同步更新。

点击「保存投屏名称」保存。接收器停止时，下次启动生效；运行中保存会重启接收器，需要在设备上重新连接。点击「启动接收器」也会验证并保存当前名称。仅输入文字不会中断正在进行的投屏。

清空输入框并保存即可恢复使用当前电脑名称。自定义基础名称仅保存在当前 Windows 用户的 `%APPDATA%\BlueberryAirPlay4K\receiver-name.txt` 中，不保留历史名称，也不随程序包分发。开机启动仍使用已有的单独设置，不会因为改名而自动开启。

## 输入限制

- 以文字或数字开头，支持中文等文字、数字、普通空格以及 `- _ . ( )（ ）`。
- 去除首尾普通空格，将 Unicode 文字规范化为 NFC；不允许换行、控制字符、引号、百分号、路径分隔符和不可见方向控制字符，避免破坏底层参数或触发环境变量展开。
- 基础名称最多 32 个 Unicode 字符，且 UTF-8 长度不超过 34 字节；全中文通常最多 11 字。为所有画质模式预留后缀空间，因此有效名称切换模式后仍然有效。
- 过长或不合法的输入会显示原因，不能保存；不会自动截断用户输入。默认电脑名称必要时按完整 Unicode 字符安全缩短。

[DNS-SD 标准 RFC 6763](https://www.rfc-editor.org/rfc/rfc6763.html#section-4.1.1) 规定服务实例标签最多 63 字节。当前接收核心的 RAOP 音频服务会在名称前附加 12 位硬件标识和 `@`，因此将完整接收名称限制在 50 个 UTF-8 字节以内，同时兼顾画面和音频服务发现。

修改名称后，iOS 设备发现列表可能短暂保留旧条目；请以控制台当前预览及运行名称为准。旧版固定名称配置仍能识别原画质，启动新版接收器时将使用新的命名规则。
